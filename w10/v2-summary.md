# 我的一人公司 v2

我的客戶是 **「卡在兩個領域中間、想做 side project 但反覆半途而廢」的同齡學生**——v1 是「想動手但不知道從哪挖」，v2 把「半途而廢」這個更深層的痛點顯化出來。

我提供 **不是一份報告、是一個會駐入你 repo 的 agent**——你拿走的不是 markdown，是 `.compass-spade/` 資料夾，它會每週看你 commit、卡關時主動講話、半年後告訴你你變成了什麼樣子。

我的 agent 部門目前有 **5 位**：COO（四問判斷 + 6 stage 工作流）、路線測繪師、鑿井匠、試刀人、**Pocket-Spade（隨身鏟，駐留型）**。

我的公司現在的「原生型」設計：**服務結束 ≠ 關係結束。Stage 6 Handoff 是新的結束點——deliverable 簽收的那一刻，Pocket-Spade 才開始上工。人類顧問做不到 24/7 駐 repo、做不到零邊際成本長期陪跑、做不到讀客戶實際 commit 而非口頭計畫——所以 Pocket-Spade 在 v1 不可能存在，在 v2 才有條件成立。**
